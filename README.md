# Filas e Algoritmos de Ordenação

Atividade do curso Técnico em Desenvolvimento de Sistemas do SENAI Félix Guisard, com exercícios de filas e algoritmos de ordenação em JavaScript.

## Exercícios

- `ex1.js`: fila de atendimento com comportamento FIFO.
- `ex2.js`: fila de prioridade para triagem, mantendo a ordem de chegada em caso de empate.
- `ex3.js`: Bubble Sort, Selection Sort e Insertion Sort com contagem de comparações e trocas.
- `ex4.js`: ranking de alunos usando `sort()` e critérios de desempate.
- `ex5.js`: desafio extra com simulação de atendimento e relatório por tempo de espera.

## Como executar

É necessário ter o Node.js instalado. No terminal, execute o exercício desejado:

```bash
node ex1.js
node ex2.js
node ex3.js
node ex4.js
node ex5.js
```

Cada arquivo pode ser executado separadamente. O exercício 5 é opcional.
